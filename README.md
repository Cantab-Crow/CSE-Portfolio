# CSE-Portfolio

## Description
Repository of all coding projects ever made for different classes or for fun, intended to act as a portfolio for future reference in a more professional capacity.

## Language
Most of the language used thus far (Fall of 2026) will be in C language. 
Not excluding the further potential of different language use. 

## Notes
Each project will have an associated file describing the different parts of the project; name, description, why it was made, how it works, and any other notes.
